Multi-Tier AI Built Into Every Workflow

Workwayz integrates generative AI across three distinct operational layers — supporting Google Gemini, OpenAI, Anthropic Claude, and 100% private Local LLMs (Ollama & LM Studio) via Google Genkit.

Layer 1 • Embedded Generators

8 One-Click Button-Based AI Assistants

Embedded directly inside project forms and tables to eliminate repetitive manual drafting: Stack Suggest, Horizontals Estimator, Story & Backlog Generator, Sub-Task & Test Case Generator, Standalone Test Case Generator, Task/Test Improvement Assistant, RAID Generators, and AI Holiday Calendar Auto-Fill.

Layer 2 • Natural Language BI

Executive & Project PromptBoards

Zero-hallucination natural language analytics across your portfolio (/fp-portfolio-dash) or individual projects (/project-details/fp-pm-dash). Renders KPI cards, interactive Recharts visualizations, CSV-exportable tables, and Scheduled AI Cron Jobs delivered straight to in-app message inboxes.

Layer 3 • Autonomous Workspace Agent

Accessible anywhere via the floating WayFinder drawer, equipped with 201 specialized tool-calling capabilities via hybrid RAG retrieval. Executes Read & Write Action Cards (create projects, draft stories, log bugs, update RAID & billing) and renders live node-and-edge dependency graphs.

Why Workwayz?

Eliminate Tool Sprawl Across Your Delivery Lifecycle

Small and medium businesses often juggle one tool for estimates, another for task boards, a third for QA test cases, spreadsheets for resource utilization and RAID logs, and separate software for client billing. Workwayz unites them all.

Disconnected Tools & Issue Trackers

  • Blind to Financials: Ticket trackers have zero concept of Fixed-Bid margins, T&M billable days, LOP deductions, role rate cards, or collected payments.
  • Velocity Distortion from Bugs: Mixing in-sprint bugs and production escaped defects either inflates sprint velocity or forces teams to reopen closed historical stories.
  • Architectural Blindspots: Stories are assigned to a single person without breaking down Frontend, Middleware, DB, and Auth system capacities.
  • Expensive Per-Seat Cloud Tax: High per-user subscription fees plus paid plugins for QA test management, roadmaps, and time tracking.

The Unified Workwayz Platform

  • Built-In Commercial Ledger: Real-time profit calculations comparing resource cost rates vs. client billing rates, fixed costs, and printable invoices.
  • Two-Tier Bug vs. Escaped Defect Architecture: In-sprint `BUG-*` items carry 0 points under parent stories, while post-acceptance `DEF-*` Escaped Defects enter the Product Backlog cleanly.
  • 3-Tier AI + 201 WayFinder Tools: One-click generators, natural-language PromptBoards with scheduled cron reports, and an autonomous workspace agent.
  • Zero-Config Local or Cloud Deployment: Run offline immediately with the Local Embedded Database (`~/.workwayz`), or connect Supabase / Firebase with $0 per-seat tax.

Built to Solve the Nuances Other Tools Ignore

Every workflow in Workwayz reflects real-world delivery governance, role separation, and operational resilience.

7-Level RBAC & Admin Separation

Granular Page and CRUD permission matrices across Super Admin, Administrator, Senior Management, Project Manager, Lead, Team Member, and PMO — with strict governance ensuring Admin accounts act purely as system administrators.

Two-Tier Bug & Escaped Defect Model

Log in-sprint `BUG-*` items under Testing linked to active stories (with 0 story points to protect velocity), and log post-acceptance production bugs as `DEF-*` Escaped Defects in the Product Backlog.

Global Worklog & Internal Messages

Team members log weekly hours across all projects from `/worklog`, and collaborate via the built-in `/messages` center supporting role/project distribution lists and automated PromptBoard cron digests.

Consolidated Lifecycle Navigation

Project tabs follow the exact delivery sequence: Initial Estimation → Project Details (incl. Releases Gantt) → Development → Testing → Resources (incl. Leaves & Holidays) → Governance → PMO → Settings.

Test Data Studio & Sandbox Seeding

Built-in synthetic data generator (`/portfolio-settings/test-data-studio`) lets administrators seed realistic portfolios, employees, stories, sprints, test cases, worklogs, and RAID items — or wipe studio batches in one click.

Archive Policies & 30-Day Trash Vault

Automate project archiving timeframes and protect both project items (`/project-trash`) and portfolio entities (`/portfolio-trash`) with a 30-day soft-delete recovery window.

Zero-Friction Deployment

Installation & 3-Minute Setup Wizard

You do not need to clone any Git repository or touch source code to run Workwayz. Launch instantly via NPX / NPM or Docker, and complete the guided 5-step In-App Setup Wizard (`http://localhost:3000/setup-wizard`).

Option 1: Instant Run via NPX / NPM (Recommended)

Requires Node.js v20+. All settings and local database records persist automatically in ~/.workwayz.

# Run instantly with zero install: npx workwayz@latest # Or install globally as a CLI app: npm install -g workwayz workwayz # Or install into a specific directory of your choosing: npm install --prefix "D:\Apps\Workwayz" workwayz npx --prefix "D:\Apps\Workwayz" workwayz # (Optional) Store local DB & config in a custom folder: node "D:\Apps\Workwayz\node_modules\workwayz\bin\workwayz.js" --data-dir "D:\Apps\Workwayz\data"

Option 2: Pre-Built Docker Container (Self-Hosting)

Run the pre-built production container from Docker Hub on any team server or cloud VM with persistent volume storage.

# Launch Workwayz production container (Docker Hub): docker run -d \ -p 3000:3000 \ -v workwayz-data:/app/data \ --name workwayz-web \ --restart always \ workwayz/workwayz:latest # (Optional) Run lightweight local Supabase on Docker: npx supabase init npx supabase start --exclude storage-api,imgproxy,edge-runtime,logflare,vector,supavisor

All data is persisted locally in ~/.workwayz (or your custom --data-dir). Pair it with Ollama or LM Studio for 100% air-gapped AI.

In-Sprint Bugs (`BUG-*`) are logged under Testing → Bugs during active sprint testing, linked to their parent Story, and carry 0 story points so team velocity is not inflated. Escaped Defects (`DEF-*`) are post-acceptance or production defects logged under Development → Product Backlog → Add Requirement → Defect. Because the original sprint is already closed, Escaped Defects are estimated and prioritized into an upcoming sprint as standalone backlog items without reopening closed historical stories.

Workwayz provides three layers of AI: (1) 8 one-click generators inside forms and tables, (2) Portfolio & Project PromptBoards that turn plain-English questions into zero-hallucination KPI cards, Recharts graphs, CSV tables, and scheduled cron report digests sent to in-app Messages, and (3) the WayFinder conversational agent equipped with 201 workspace tools to read/write records via confirmation cards and render live dependency graphs.

Workwayz enforces RBAC across 7 roles: Super Admin, Administrator, Senior Management, Project Manager, Lead, Team Member, and PMO. Super Admin and Administrator accounts govern system infrastructure, user enablement, and permissions, and cannot be staffed on projects as delivery resources. Every other role sees a dynamically tailored workspace and project lifecycle navigation bar.

Navigate to Portfolio Settings → Test Data Studio (/portfolio-settings/test-data-studio) as a Super Admin or Administrator. You can generate realistic synthetic portfolios, users across all access levels, active projects (complete with stories, sprints, test cases, worklogs, and RAID items), and initial estimations — and cleanly wipe studio-generated batches whenever you're ready for production.
